# MedFlow Connect

A responsive, front-end healthcare appointment management system prototype for the Web System Development Project.

## Live demo
Open `index.html` in a browser, or enable GitHub Pages for this repository. No build step or server is required.

## Demo accounts

| Role | Email | Password |
|---|---|---|
| Patient | `patient@medflow.test` | `demo123` |
| Doctor | `doctor@medflow.test` | `demo123` |
| Administrator | `admin@medflow.test` | `demo123` |

## Included functionality

- Role-based patient, doctor, and administrator dashboards
- Doctor directory with specialty search
- Appointment booking with date/time and duplicate-slot validation
- Appointment history, cancellation, and status tracking
- Staff schedule, patient directory, and confirmation workflow
- Responsive mobile-friendly interface
- Browser persistence using `localStorage` and `sessionStorage`

## Important prototype note
This is an educational front-end prototype. It uses browser storage and demo credentials only; it does not store real medical information and must not be used for production healthcare operations without a secure backend, authentication, authorization, audit logging, encryption, and compliance review.
